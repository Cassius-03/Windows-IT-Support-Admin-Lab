**PROJECT OVERVIEW**

**Windows IT Support & System Administration Lab**

**1. Purpose**

To develop practical IT support and Windows administration skills through simulated workplace scenarios.

**2. Scenario**

I am simulating the role of an entry-level IT Support Technician responsible for maintaining and troubleshooting a company's Windows 11 workstation.

My responsibilities include:

Inspecting computer hardware and software.
Creating and managing employee accounts.
Managing user access and permissions.
Investigating operating system errors.
Diagnosing network problems.
Monitoring computer performance.
Automating administrative tasks using PowerShell.
Documenting and resolving support tickets.

**3. Learning Approach**

Each module follows this process:

Understand the technical concept.
Perform a practical exercise.
Collect evidence through screenshots.
Document the results.
Investigate errors and unexpected results.
Record lessons learned.

**4. Tools and Technologies**

Windows 11 Home
Windows PowerShell
Git
GitHub
Windows Administration Tools

**5. Expected Outcome**

Build a practical portfolio demonstrating foundational Windows IT Support and System Administration skills.

The portfolio will contain:

Technical documentation.
PowerShell scripts.
Practical exercise screenshots.
IT support ticket reports.
Troubleshooting records.

**6. Project Scope**

This project focuses on foundational Windows workstation administration and entry-level IT support responsibilities.

All exercises will be performed in a controlled personal learning environment.

**7. Project Status**

Currently developing the project structure and completing practical administration modules.
