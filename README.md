**Windows IT Support & System Administration Lab**


**PROJECT OVERVIEW**

This project documents my practical learning journey in Windows IT Support and System Administration.

I am simulating the role of an entry-level IT Support Technician responsible for maintaining and troubleshooting a Windows 11 workstation.

**Objectives**

- Inspect computer hardware and software.
- Create and manage local Windows user accounts.
- Manage user access and permissions.
- Investigate Windows operating system errors.
- Diagnose network connectivity problems.
- Monitor system performance.
- Automate administrative tasks using PowerShell.
- Document and resolve IT support tickets.

Learning Approach

Each module follows these steps:

Understand the technical concept.
Perform a practical exercise.
Collect screenshots and evidence.
Document the results.
Investigate errors and challenges.
Record lessons learned.
Purpose

The goal of this project is to develop practical Windows IT Support and System Administration skills while building a professional portfolio demonstrating foundational technical knowledge.

Note: This is a personal learning lab. All exercises are performed in a controlled environment.
